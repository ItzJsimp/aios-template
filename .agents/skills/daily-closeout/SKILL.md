# Daily Closeout: Evening Wrap-Up & Workspace Hygiene Gate

Conduct a low-friction evening closeout for {{AIOS_NAME}}.

## Protocol
1. **Accomplishments Audit:** Review commits made today to acknowledge completed wins.
2. **Workspace Hygiene Gate:** Check for uncommitted git changes and unstaged notes.
3. **Capture Loose Ends:** Ensure all open questions or unresolved thoughts are saved to `tasks/` or `capture/`.
4. **Tomorrow's Seed Priority:** Define the exact first action to tackle tomorrow morning.
